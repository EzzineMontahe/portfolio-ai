# Portfolio AI — Montahe Ezzine

Personal portfolio website with embedded AI assistant built with Next.js + Groq API.

## Features
- AI chat assistant powered by Groq (llama-3.3-70b-versatile)
- Responsive design — mobile + desktop
- Project showcase
- Direct contact options (Upwork, LinkedIn, Email)

## Tech Stack
- Next.js 16
- Groq API
- Tailwind CSS
- Chakra Petch font
